# Support and Feedback

For problems with Better Tooltips, please use the GitHub issue tracker:

- [Report a bug](https://github.com/Tobias004/filesystem_dock_tooltips/issues/new?template=bug_report.yml)
- [Send feedback / request a feature](https://github.com/Tobias004/filesystem_dock_tooltips/issues/new?template=feedback.yml)

When reporting a bug, include the Better Tooltips and Godot versions, the operating system, a brief reproduction procedure, and relevant error messages. Screenshots or a minimal reproduction project can help.

The same feedback links are available in Godot under **Project > Tools > Better Tooltips** when the add-on is enabled.
