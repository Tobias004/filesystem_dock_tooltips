# Tooltip modules

All switches are in `tooltip_settings.gd`.

| Constant | Module | Preview |
| --- | --- | --- |
| `ENABLE_SCRIPT_DOCUMENTATION` | existing GDScript module | `class_name` + `##` documentation |
| `ENABLE_MATERIAL_PREVIEW` | material | generated 3D sphere |
| `ENABLE_MESH_PREVIEW` | mesh | generated 3D geometry, automatic camera fit |
| `ENABLE_FONT_PREVIEW` | font | rendered text samples |
| `ENABLE_SHADER_PREVIEW` | shader | spatial sphere / canvas-item test texture |
| `ENABLE_SPRITE_FRAMES_PREVIEW` | SpriteFrames | contact sheet |
| `ENABLE_THEME_PREVIEW` | theme | representative controls |
| `ENABLE_STYLEBOX_PREVIEW` | StyleBox | representative panel |
| `ENABLE_CURVE_PREVIEW` | curve | graph / fitted 2D / projected 3D |
| `ENABLE_GRADIENT_PREVIEW` | gradient | generated gradient over checkerboard |
| `ENABLE_ENVIRONMENT_PREVIEW` | environment | fixed reference scene |
| `ENABLE_SKY_PREVIEW` | sky | fixed wide-angle view |

`DEBUG_MESSAGES` controls only messages generated by this add-on.

The modules deliberately do not duplicate Godot's own texture and audio tooltip
previews. PackedScene auto-rendering is deliberately excluded.

Release configuration: `DEBUG_MESSAGES := false`; all modules enabled.
